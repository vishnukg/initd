# dnf packages installed by linux/bootstrap.sh.
# One package per line, comments start with #.
# Targets Fedora Workstation 44+. hyprland/hyprlock/hypridle/hyprpaper/
# xdg-desktop-portal-hyprland come from the sdegler/hyprland COPR, hyprmoncfg
# from paolino/hyprmoncfg, and ghostty from scottames/ghostty — none are in
# Fedora's official repos. install_packages() enables all three COPRs before
# resolving this list.
#
# kitty is the one package here that exists in BOTH: Fedora ships 0.47.1 in
# updates, and sdegler/hyprland carries 0.48.2, so dnf resolves it from the COPR
# on version. Accepted rather than pinned — that COPR already supplies Hyprland
# itself, so it is not a new dependency, and if it disappears kitty falls back to
# Fedora's build on the next `dnf upgrade` with no action needed.

# ── Audio tuning ──────────────────────────────────────────────────────────────
# EasyEffects sits between apps and the speakers with a live-tunable EQ /
# compressor / limiter. Its effects are LV2 plugins it only *recommends*, and
# bootstrap installs with weak deps off, so the ones it actually loads are
# listed here: LSP (equalizer, compressor, limiter), Calf (bass enhancer,
# exciter), Zam (a few dynamics). mdala and the Breeze theme are skipped.
easyeffects
lsp-plugins-lv2
lv2-calf-plugins
lv2-zam-plugins
