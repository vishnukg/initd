# Cosmos wallpaper collection

12 original-resolution astronomy JPEGs. Start with [the gallery](index.html) or [the numbered preview sheet](preview.jpg). The gallery includes a 16:10 desktop-crop toggle. Original files have not been resized, recoloured or cropped.

Suggested starting points: **01** and **02** for subdued blue clouds; **05** and **07** for stronger teal; **06** for a blue star cluster.
